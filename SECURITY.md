# Security Policy

## Supported versions

Unless a repository's own `SECURITY.md` says otherwise, only the latest release — or the `main`
branch, for projects without releases — is supported: security fixes land on `main` and ship in
the next release.

## Reporting a vulnerability

Please use the repository's **Security** tab → **Report a vulnerability** (GitHub private
vulnerability reporting) instead of filing a public issue. If private reporting is unavailable on
a particular repository, contact the maintainer privately.
